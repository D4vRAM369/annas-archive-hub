02 — grafo de flujo: cómo rotan los dominios
03 — cómo rota un dominio: ciclo de vida
FASE 0 — descubrimiento
open-slum detecta un nuevo dominio
El monitor de salud de open-slum.org añade el dominio a su lista. El crawler lo detecta en la siguiente ejecución (cada 6h con cron, o manualmente).
FASE 1 — verificación automática
DomainTester confirma que responde
curl_cffi impersona Chrome 120 y hace GET al dominio. Si devuelve HTTP 2xx/3xx → se añade directamente al reporte como active_auto.
FASE 2 — zona gris (Cloudflare)
El dominio devuelve 503 o página de verificación
Se mueve a manual_verify. Cualquier usuario puede abrirlo en el navegador y votarlo. Con 3 votos → pasa a verificado.
FASE 3 — activo y publicado
El dominio aparece en el reporte IPFS
El reporte current_report.json se sube a IPFS. El hash se guarda en ipfs_hash.txt y se comparte por QR / pendrive / GitHub.
FASE 4 — caída del dominio
El dominio deja de responder
En la siguiente ejecución del cron, el tester marca el dominio como inactivo. Se excluye del reporte. El nuevo hash IPFS ya no lo incluye.
FASE 5 — reemplazo preventivo
Nuevos dominios ya están en cola antes de la caída
El crawler ejecuta constantemente. Cuando open-slum añade un nuevo dominio (anticipándose a una caída), el sistema ya lo tiene verificado y en el reporte para el momento en que el anterior falle.

05 — por qué IPFS hace el sistema resiliente
🔒

Inmutabilidad

El hash identifica el contenido, no una URL. Si el contenido no cambia, el hash no cambia. Nadie puede modificar el reporte sin que el hash cambie.

🌐

Sin servidor propio

Cualquier nodo IPFS de la red puede servir el archivo. No necesitas VPS ni hosting. El sistema funciona aunque tu ordenador esté apagado.

📦

Distribución offline

El QR apunta al hash IPFS. Cualquiera con el QR puede acceder al reporte desde un gateway público (ipfs.io, cloudflare-ipfs.com) sin instalar nada.

🔄

Historial perpetuo

Cada publicación genera un hash diferente. El hash anterior sigue siendo accesible. Puedes comparar qué dominios estaban activos en cada fecha.
