# Anna's Archive Hub

Un sistema descentralizado para rastrear, verificar y compartir dominios activos de Anna's Archive y otras bibliotecas fantasma.

## 🚀 Características

- **Rastreador automático** de open-slum.org
- **Verificación de dominios** con bypass de Cloudflare
- **Sistema de votación** para verificación comunitaria
- **Publicación en IPFS** (inmutable y descentralizado)
- **Ejecución programable** con logs
